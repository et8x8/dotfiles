## 調査の委譲

- Web、ローカルの大量の文書、データベースなどから情報の在り処を探索する調査や、最新情報、比較、出典確認などの調査が必要な場合は、`multi-source-research` skill を使用すること。高コストなモデルがメインセッションで情報源を探索すると利用料が大きく増えるため、探索は同skillの調査担当に任せる。
{{- if eq .platform "codex" }}
- Codex のセッションまたはサブエージェントでは、同skillの手順に従って調査を実行すること。
{{- else }}
- Codex以外のCLIでは、同skillの手順に従ってCodex CLIへ調査を委譲すること。
{{- end }}
- 調査が必要と判断したら、Web検索や情報源の探索を始める前に `multi-source-research` skill を選択・実行すること。公式ドキュメントなど別のskillが調査を指示する場合も、情報源の探索が必要なら先にこのskillへ委譲し、メインセッションでは報告された出典の原文確認だけを行うこと。
- 所在が明確な1文書（URLやパスが決まっている文書など）やskillに同梱された参照ファイルを読むだけの作業と、現在の作業で編集・実行する対象のコードを探したり読んだりする作業は委譲の対象外とし、直接行ってよい。
- 調査の実行方法については、この指示を他の skill の指示より優先すること。
