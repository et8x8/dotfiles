# /test

dev-flow の Test 工程を起動する。

## 動作

1. `docs/spec/` を読み、現状のテストとの差分を把握する。
2. **`test-author` サブエージェントを spawn する**。
3. `update-test` skill の手順に従い、テストコードを作成 / 更新させ、テストを実行して**失敗**を確認させる。
4. 完了したら、追加 / 変更 / 削除されたテスト ID と実行結果 (期待通り失敗したか) を報告する。

## 引数

引数は任意。何も無ければ Spec 全体に対応するテストの差分を反映する。

## 完了後の案内

新規 / 変更テストが期待通り失敗することを確認したら、次は `/implement` を実行するよう案内する。
